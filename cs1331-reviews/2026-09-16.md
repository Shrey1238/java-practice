## 1. Two-minute recap of Monday (Sep 14)

Monday was about **static methods** and finishing **console I/O**. Make sure these are solid — today builds directly on them.

- **Static method anatomy:** `public static <returnType> name(<params>) { ... }`. Called as `ClassName.name(args)` (or just `name(args)` from inside the same class).
- **Pass by value (9.10):** Java *always* copies the argument into the parameter. For primitives that's a copy of the value; for objects it's a copy of the *reference*, so the method can mutate the object but can't rebind the caller's variable.
- **Scope (9.13):** a variable lives from its declaration to the end of the `{ }` block it's declared in. Parameters are scoped to the whole method body. You can't declare two locals with the same name in overlapping scopes.
- **Ambiguous invocation:** if two overloads match equally well (e.g. `f(int, double)` and `f(double, int)` called with `f(1, 2)`), the compiler refuses. Fix by casting one argument.
- **printf cheat sheet:** `%d` int, `%f` float/double (`%.2f` → 2 decimals), `%s` string, `%c` char, `%b` boolean, `%n` newline, `%8.2f` = width 8, 2 decimals.
- **Checkstyle:** the course style checker (indentation, naming, line length ≤ 100, Javadoc, no magic numbers in some configs). Run it on PE03 before you submit.

> Quick check: what does this print?

## 2. Today's concepts — read this before lecture

### A. Packages

A **package** is a namespace (a folder) that groups related classes and avoids name collisions.

```java
package edu.gatech.cs1331.hw3;   // must be the FIRST statement in the file (before imports)

import java.util.Scanner;        // bring one class into scope
import java.util.*;              // or every class in the package (wildcard; not sub-packages)
```

Things to know:
- File location must match: `package a.b;` ⇒ file lives in `a/b/`. Compile from the root: `javac a/b/Foo.java`, run with `java a.b.Foo`.
- `java.lang` (String, Math, System, Integer, …) is imported **automatically**. Everything else (`java.util.Scanner`, `java.util.Random`) must be imported or fully qualified.
- Fully-qualified name works without an import: `java.util.Random r = new java.util.Random();`
- Two classes with the same simple name in different packages? Import one, fully-qualify the other.
- Convention: package names are all lowercase, reverse-domain style (`com.company.project`).
- **Default (no) package**: fine for tiny programs, avoid for anything real.

### B. `Random` (9.6.2)

```java
import java.util.Random;

Random rand = new Random();          // seeded from the clock → different each run
Random fixed = new Random(42);       // same seed → same sequence every run (great for testing)

int d6      = rand.nextInt(6) + 1;   // nextInt(bound) gives 0..bound-1, so +1 → 1..6
int inRange = rand.nextInt(10, 20);  // Java 17+: 10..19 (bound exclusive)
double u    = rand.nextDouble();     // [0.0, 1.0)
boolean b   = rand.nextBoolean();
```

- `Random` is a **class you instantiate** (compare with `Math.random()` which is a static method returning a `double` in `[0,1)`).
- Pattern for a random int in `[lo, hi]` inclusive: `lo + rand.nextInt(hi - lo + 1)`.
- Same seed ⇒ same sequence. That's why autograders love seeded `Random`.

### C. `Math` (4.1–4.2, 2.9.3, 6.10)

`Math` is a **utility class**: every method is `static`, you never write `new Math()`.

| Method | Returns | Notes |
|---|---|---|
| `Math.abs(x)` | same type as x | |
| `Math.pow(a, b)` | `double` | even for int args — cast if you need an int |
| `Math.sqrt(x)` | `double` | |
| `Math.max(a,b)` / `Math.min(a,b)` | same type | |
| `Math.round(x)` | `long` (for double), `int` (for float) | rounds half up |
| `Math.floor(x)` / `Math.ceil(x)` | `double` | `floor(-2.5)` = `-3.0` |
| `Math.random()` | `double` in [0,1) | `(int)(Math.random() * 6) + 1` → die roll |
| `Math.PI`, `Math.E` | `double` constants | |
| `Math.sin/cos/tan`, `Math.toRadians`, `Math.toDegrees` | `double` | trig works in **radians** |
| `Math.log(x)` (natural), `Math.log10(x)`, `Math.exp(x)` | `double` | |

Pitfalls from 2.9.3 (numeric conversions) that show up with `Math`:
- `Math.pow(2, 3)` is `8.0`, a `double`. `int eight = (int) Math.pow(2, 3);`
- `Math.round(2.5)` → `3`, `Math.round(-2.5)` → `-2` (rounds toward +∞ on ties).
- Integer division happens *before* you hand things to `Math`: `Math.sqrt(7 / 2)` is `sqrt(3)`, not `sqrt(3.5)`.

### D. Enumerations (Appendix I)

An **enum** is a type with a fixed set of named constants. Use it instead of "magic" ints or strings.

```java
public enum Day { MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY }

Day today = Day.WEDNESDAY;

// Built-in goodies
today.name()            // "WEDNESDAY" (a String)
today.ordinal()         // 2 (zero-based position)
today.toString()        // "WEDNESDAY" by default
Day.valueOf("FRIDAY")   // Day.FRIDAY  (throws IllegalArgumentException if no match)
Day.values()            // Day[] of all constants, in declaration order
today == Day.WEDNESDAY  // compare enums with ==  (they're singletons)
today.compareTo(Day.FRIDAY) // negative: compares by ordinal

switch (today) {
    case MONDAY, FRIDAY -> System.out.println("Lecture day");
    case WEDNESDAY      -> System.out.println("PE due!");
    default             -> System.out.println("Recitation / rest");
}
```

Key points:
- Constants are conventionally `ALL_CAPS`.
- Inside a `switch` on an enum you write the bare constant (`case MONDAY`), **not** `Day.MONDAY`.
- Enums can live in their own file (`Day.java`) or be nested inside a class.
- Preview of what's coming later in the course: enums can also have fields, constructors, and methods — don't worry about that yet.

   <details><summary>Answer</summary><code>String</code> and <code>Math</code> (both in <code>java.lang</code>). <code>Scanner</code> and <code>Random</code> need <code>import java.util.*</code>.</details>
2. Write one expression that gives a random integer from 5 to 15 inclusive using a `Random rand`.
   <details><summary>Answer</summary><code>5 + rand.nextInt(11)</code> (11 = 15 − 5 + 1). Or <code>rand.nextInt(5, 16)</code> on Java 17+.</details>
3. What is the type and value of `Math.pow(3, 2) + Math.round(2.5)`?
   <details><summary>Answer</summary><code>double</code>, value <code>12.0</code> (9.0 + 3 → 3 is a <code>long</code>, promoted to double).</details>

   <details><summary>Answer</summary>Throws <code>IllegalArgumentException</code> — <code>valueOf</code> is case-sensitive; there is no constant named <code>m</code>.</details>
