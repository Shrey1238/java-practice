## 2. Today's concepts — arrays

### A. 1-D arrays (7.1–7.9)

```java
int[] scores = new int[5];            // 5 slots, all 0  (defaults: 0, 0.0, false, '\u0000', null)
int[] primes = {2, 3, 5, 7, 11};       // array initializer (only at declaration)
String[] names = new String[3];       // all null!

scores[0] = 90;                        // index from 0 ... length-1
int n = scores.length;                 // .length is a FIELD, not a method (no parentheses!)
scores[5] = 1;                         // ArrayIndexOutOfBoundsException at runtime
```

Things you must know cold:
- **Arrays are objects.** `int[] a` holds a *reference*. `int[] b = a;` makes `b` point at the **same** array (aliasing). `a == b` compares references, not contents.
- **Size is fixed** once created. To "grow", allocate a new bigger array and copy.
- **Iteration**
  ```java
  for (int i = 0; i < a.length; i++) { a[i] *= 2; }   // index loop: can modify elements
  for (int x : a) { System.out.println(x); }          // for-each: read-only view of elements (assigning to x does NOT change a)
  ```
- **Copying** (7.6): `System.arraycopy(src, 0, dst, 0, src.length)`, `Arrays.copyOf(a, newLen)`, or `a.clone()`. Assignment `b = a` is **not** a copy.
- **Passing to methods (7.7–7.8):** the reference is copied ⇒ the method can change the elements, but reassigning the parameter to a new array doesn't affect the caller.
- **Returning arrays:** perfectly fine: `static int[] reverse(int[] a) { ... return result; }`
- **Varargs (7.9):** `static int sum(int... nums)` — inside the method `nums` is an `int[]`; callers can pass `sum(1,2,3)` or `sum(arr)`.
- **`java.util.Arrays` helpers (7.13):** `Arrays.toString(a)`, `Arrays.fill(a, 7)`, `Arrays.equals(a, b)` (content comparison), `Arrays.sort(a)`.
  - Printing an array directly (`System.out.println(a)`) gives garbage like `[I@1b6d3586` — use `Arrays.toString`.

### B. Arrays of objects (9.11)

```java
Circle[] circles = new Circle[3];     // three NULL references, no Circle objects yet
circles[0].getRadius();               // NullPointerException!
for (int i = 0; i < circles.length; i++) {
    circles[i] = new Circle(i + 1);   // now each slot holds an object
}
```

The "array of nulls" trap is one of the most common exam questions.

### C. 2-D arrays (8.1–8.5)

A 2-D array is an **array of arrays** (each row is its own 1-D array object).

```java
int[][] grid = new int[3][4];         // 3 rows, 4 columns, all 0
int[][] tri  = {{1}, {2, 3}, {4, 5, 6}};   // ragged: rows can have different lengths

grid[1][2] = 7;                       // row 1, column 2
grid.length                           // number of rows (3)
grid[0].length                        // number of columns in row 0 (4)

for (int r = 0; r < grid.length; r++) {
    for (int c = 0; c < grid[r].length; c++) {   // use grid[r].length, not a hard-coded 4 — handles ragged arrays
        System.out.print(grid[r][c] + " ");
    }
    System.out.println();
}

for (int[] row : grid) {              // for-each over rows
    for (int v : row) { ... }
}
```

- **Ragged arrays:** `int[][] jag = new int[3][];` then `jag[0] = new int[2]; jag[1] = new int[5];`
- Rows are independently swappable: `int[] t = g[0]; g[0] = g[1]; g[1] = t;` swaps rows in O(1).
- Aliasing applies per row: `int[] r = grid[0]; r[0] = 99;` changes `grid[0][0]`.

### D. X-D (multidimensional) arrays (8.8)

Same idea, one more bracket: `int[][][] cube = new int[2][3][4];` → `cube.length == 2`, `cube[0].length == 3`, `cube[0][0].length == 4`. Triple-nested loops. Rare in practice, but know how `.length` works at each level.

## 3. Self-check (~5 min)

1. What prints?
   ```java
   int[] a = {1, 2, 3};
   int[] b = a;
   b[0] = 10;
   System.out.println(a[0] + " " + (a == b) + " " + a.equals(b));
   ```
   <details><summary>Answer</summary><code>10 true true</code> — same object; <code>==</code> and <code>equals</code> both compare references for arrays.</details>
2. What's the value of `m.length` and `m[2].length` for `int[][] m = {{1,2},{3},{4,5,6}};`?
   <details><summary>Answer</summary>3 and 3.</details>
3. Does this change the array? `for (int x : a) { x = 0; }`
   <details><summary>Answer</summary>No. <code>x</code> is a copy of each element.</details>
4. What exception, if any: `String[] s = new String[2]; System.out.println(s[0].length());`
   <details><summary>Answer</summary><code>NullPointerException</code> — <code>s[0]</code> is <code>null</code>.</details>
5. Write a static method that returns the sum of all elements of a `double[][]`.
   <details><summary>Answer</summary><pre>static double total(double[][] m) {
    double sum = 0;
    for (double[] row : m) for (double v : row) sum += v;
    return sum;
}</pre></details>
