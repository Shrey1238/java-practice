## 2. The ten most common Exam 1 mistakes

1. `int / int` truncates. `7 / 2 == 3`. Always ask: "are both operands ints?"
2. `(int) 3.99` is `3`, not `4`. Casting truncates toward zero.
3. `==` on Strings compares references; use `.equals`.
4. `Math.pow` returns `double`. `int x = Math.pow(2, 3);` does not compile.
5. `s.substring(a, b)` — `b` is **exclusive**; `s.charAt(s.length())` is out of bounds.
6. Forgetting `break` in classic `switch` ⇒ fall-through.
7. `Scanner.nextInt()` followed by `nextLine()` reads the leftover newline as an empty string.
8. `array.length` (no parens) vs `string.length()` (parens) vs `list.size()` (later).
9. Modifying elements in a for-each loop does nothing; `new String[3]` is 3 `null`s.
10. Off-by-one on loop bounds: `i <= a.length` throws `ArrayIndexOutOfBoundsException`.

## 3. Compile error vs. runtime error — know the difference

| Compile-time (javac complains) | Runtime (exception while running) |
|---|---|
| type mismatch: `int x = 2.5;` | `ArrayIndexOutOfBoundsException` |
| missing semicolon / brace | `NullPointerException` |
| using an undeclared or out-of-scope variable | `ArithmeticException` (`/ by zero` — **ints only**; doubles give `Infinity`/`NaN`) |
| "variable might not have been initialized" (locals) | `InputMismatchException` (Scanner got text, expected int) |
| ambiguous method call | `StringIndexOutOfBoundsException` |
| static method touching instance field | `NumberFormatException` (`Integer.parseInt("abc")`) |
| unreachable code after `return` | |

If a question asks "does this compile?", check types and scope *first*, then think about runtime.

## 4. printf quick reference (frequent short-answer item)

```java
System.out.printf("%d|%5d|%-5d|%05d%n", 42, 42, 42, 42);   // 42|   42|42   |00042
System.out.printf("%.2f|%8.3f|%e%n", 3.14159, 3.14159, 31415.9); // 3.14|   3.142|3.141590e+04
System.out.printf("%s|%10s|%-10s|%c|%b%n", "hi", "hi", "hi", 'x', true);
```
