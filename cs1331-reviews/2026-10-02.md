## 2. Today's concepts

### A. Wrapper classes (10.7)

Every primitive has an object "wrapper" in `java.lang`:

| primitive | wrapper | | primitive | wrapper |
|---|---|---|---|---|
| `int` | `Integer` | | `double` | `Double` |
| `char` | `Character` | | `boolean` | `Boolean` |
| `long` | `Long` | | `float` | `Float` |
| `byte` | `Byte` | | `short` | `Short` |

Why they exist: generics/collections (`ArrayList<Integer>`, not `ArrayList<int>`), the ability to be `null`, and a home for utility methods.

```java
Integer boxed = 5;               // autoboxing: int → Integer
int prim = boxed;                // auto-unboxing
Integer n = null; int x = n;     // NullPointerException on unboxing!

Integer.parseInt("42")           // String → int  (NumberFormatException if not a number)
Double.parseDouble("3.5")
Integer.valueOf("42")            // String → Integer
Integer.MAX_VALUE, Integer.MIN_VALUE
Integer.toString(42), String.valueOf(42)
Character.isDigit('7'), Character.isLetter('a'), Character.toUpperCase('a')
Integer.compare(a, b)            // -1/0/1
```

**Trap:** `Integer a = 1000, b = 1000; a == b` is `false` (different objects) but `a.equals(b)` is `true`. Small values (−128..127) are cached so `==` *happens* to work — never rely on it. **Use `equals` for wrappers.**

Wrappers are **immutable** (like `String`).

### B. Inheritance (11.1–11.3) — "is-a"

A **subclass** `extends` a **superclass**, inheriting its fields and methods, and can add more or change behavior.

```java
public class Animal {
    private String name;
    public Animal(String name) { this.name = name; }
    public String getName() { return name; }
    public String speak() { return "..."; }
}

public class Dog extends Animal {
    private String breed;
    public Dog(String name, String breed) {
        super(name);            // call the SUPERCLASS constructor — must be first statement
        this.breed = breed;
    }
    public String fetch() { return getName() + " fetches!"; }   // new behavior; getName() inherited
}

Dog d = new Dog("Rex", "lab");
d.getName();   // inherited
d.fetch();     // Dog-specific
```

Key rules:
- Java has **single inheritance**: one direct superclass. Every class without an explicit `extends` extends `Object`.
- `private` members **are inherited but not accessible** in the subclass — use the parent's public getters/setters (or `protected`, coming Wed).
- **Constructors are not inherited.** A subclass constructor must call a superclass constructor:
  - explicitly with `super(args)` as the first statement, **or**
  - implicitly — Java inserts `super();` for you. If the parent has **no no-arg constructor**, that implicit call fails to compile. (Very common HW/exam error.)
- A constructor has either `this(...)` or `super(...)` first, never both.
- Construction order: superclass constructor body runs **before** the subclass constructor body (all the way up from `Object` down).
- `super.method()` calls the parent's version of a method (needed once you override — next week).

**Subclass reference compatibility (preview of polymorphism):** `Animal a = new Dog("Rex", "lab");` is legal — a Dog *is an* Animal. `a.fetch()` won't compile though: the compiler only knows `a` is an `Animal`. Full story on Oct 19.

**Is-a vs has-a smell test:** *"A `Dog` is an `Animal`"* ✓ inheritance. *"A `Car` is an `Engine`"* ✗ — a Car **has** an Engine ⇒ field.

### C. `final` classes (11.15)

`final` has three meanings depending on where it sits:

| on a | means |
|---|---|
| variable | assigned exactly once (constant) |
| method | cannot be overridden by subclasses (Oct 16 detail) |
| **class** | **cannot be extended** — e.g. `public final class String` |

Why make a class final? Security and immutability guarantees (nobody can subclass `String` and break its invariants), and simpler reasoning about behavior.

### D. Async: JavaDocs (1.9.1) — read this weekend

```java
/**
 * Represents a bank account with an owner and balance.
 *
 * @author Your Name
 * @version 1.0
 */
public class Account {
    /**
     * Withdraws the given amount if funds are sufficient.
     *
     * @param amount the amount to withdraw; must be positive
     * @return true if the withdrawal succeeded, false otherwise
     * @throws IllegalArgumentException if amount is negative
     */
    public boolean withdraw(double amount) { ... }
}
```

- Starts with `/**`, placed directly above a class, constructor, method, or field.
- Tags: `@param`, `@return` (omit for `void`), `@throws`, `@author`, `@version`.
- Generate HTML: `javadoc -d docs *.java`. Checkstyle in this course checks for missing Javadoc on public members.

1. What happens?
   ```java
   class A { A(int x) {} }
   class B extends A { B() { System.out.println("B"); } }
   ```
   <details><summary>Answer</summary>Compile error: <code>B()</code> implicitly calls <code>super()</code>, but <code>A</code> has no no-arg constructor. Fix: <code>B() { super(0); ... }</code>.</details>
2. Output?
   ```java
   class P { P() { System.out.print("P"); } }
   class C extends P { C() { System.out.print("C"); } }
   new C();
   ```
   <details><summary>Answer</summary><code>PC</code> — parent constructor runs first.</details>
3. `Integer a = 127, b = 127, c = 128, d = 128;` — `a == b`? `c == d`? `c.equals(d)`?
