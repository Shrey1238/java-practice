## 1. Five traces (write your answer before expanding — ~10 min)

**1. Constructor order**
```java
class A { A() { System.out.print("A"); } }
class B extends A { B() { System.out.print("B"); } }
class C extends B { C() { super(); System.out.print("C"); } }
new C();
```
<details><summary>Answer</summary><code>ABC</code> — parent constructors always run first.</details>

**2. Static vs instance**
```java
class Counter {
    static int total = 0; int mine = 0;
    Counter() { total++; mine++; }
}
Counter x = new Counter(), y = new Counter(), z = new Counter();
System.out.println(Counter.total + " " + y.mine);
```
<details><summary>Answer</summary><code>3 1</code></details>

**3. Dynamic dispatch vs. compile-time type**
```java
class Shape { String name() { return "shape"; } }
class Sq extends Shape { @Override String name() { return "square"; } String side() { return "4"; } }
Shape s = new Sq();
System.out.println(s.name());
System.out.println(s.side());
```
<details><summary>Answer</summary>First line prints <code>square</code> (run-time type). Second line is a <b>compile error</b> — <code>Shape</code> has no <code>side()</code>. Would need <code>((Sq) s).side()</code>.</details>

**4. Aliasing through a shallow copy**
```java
class Box { int[] items; Box(int[] items) { this.items = items; } Box(Box o) { this.items = o.items; } }
int[] arr = {1, 2};
Box b1 = new Box(arr);
Box b2 = new Box(b1);
b2.items[0] = 99;
System.out.println(b1.items[0]);
```
<details><summary>Answer</summary><code>99</code> — shallow copy shares the array. Deep copy would use <code>Arrays.copyOf</code>.</details>

**5. equals / hashCode**
```java
class P {
    int v; P(int v) { this.v = v; }
    @Override public boolean equals(Object o) { return o instanceof P && ((P) o).v == v; }
}
P a = new P(1), b = new P(1);
System.out.println(a.equals(b) + " " + (a == b) + " " + (a.hashCode() == b.hashCode()));
```
<details><summary>Answer</summary><code>true false</code> and then <b>almost certainly <code>false</code></b> — <code>hashCode</code> wasn't overridden, so equal objects have different hashes: a contract violation the exam may ask you to spot/fix.</details>

## 2. "Does it compile?" hit list — know these cold

| snippet | verdict |
|---|---|
| `public void Dog(String n) { … }` inside `class Dog` | compiles, but it's a *method* not a constructor (return type present) |
| `Dog() { System.out.println("hi"); this("x"); }` | ✗ `this()` must be first |
| `class B extends A { B() {} }` where A has only `A(int)` | ✗ implicit `super()` has no target |
| subclass overrides `public` method as `protected` | ✗ can't narrow visibility |
| `static void f() { System.out.println(this.x); }` | ✗ no `this` in static context |
| `final int x; x = 1; x = 2;` | ✗ reassigning final |
| `class D extends FinalClass {}` | ✗ final class |
| `Integer i = null; int j = i;` | compiles; NPE at run time |
| `Object o = new Dog(); o.bark();` | ✗ `Object` has no `bark()` |
| `@Override public boolean equals(Dog d)` | ✗ doesn't override `equals(Object)` |

## 3. Write-a-class template (30 seconds to rehearse mentally)

```java
public class Thing extends Parent {
    private final int id;               // fields private
    private String label;

    public Thing(int id, String label) { super(label.length()); this.id = id; this.label = label; }
    public Thing(int id) { this(id, "none"); }                       // chain
    public Thing(Thing other) { this(other.id, other.label); }       // copy ctor

    public int getId() { return id; }
    public String getLabel() { return label; }
    public void setLabel(String label) { if (label != null) this.label = label; }

    @Override public String toString() { return "Thing[" + id + ", " + label + "]"; }
    @Override public boolean equals(Object o) {
        if (this == o) return true;
        if (!(o instanceof Thing)) return false;
        Thing t = (Thing) o;
        return id == t.id && label.equals(t.label);
    }
    @Override public int hashCode() { return Objects.hash(id, label); }
}
```
