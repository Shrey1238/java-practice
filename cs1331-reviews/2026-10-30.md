## 2. Today's concepts

### A. Bubble sort — idea

Repeatedly sweep left→right comparing **adjacent** pairs and swapping if out of order. After pass *k*, the *k* largest elements are in their final positions at the right end ("bubbled up").

```java
public static void bubbleSort(int[] a) {
    int n = a.length;
    for (int i = 0; i < n - 1; i++) {                  // passes
        boolean swapped = false;
        for (int j = 0; j < n - 1 - i; j++) {          // last i elements already in place
            if (a[j] > a[j + 1]) {
                int tmp = a[j]; a[j] = a[j + 1]; a[j + 1] = tmp;
                swapped = true;
            }
        }
        if (!swapped) break;                           // early exit: already sorted
    }
}
```

Trace `{5, 1, 4, 2}`:
- pass 0: (5,1)→swap `{1,5,4,2}`; (5,4)→swap `{1,4,5,2}`; (5,2)→swap `{1,4,2,5}`
- pass 1: (1,4) ok; (4,2)→swap `{1,2,4,5}`
- pass 2: (1,2) ok → no swaps → break.

### B. Complexity

| case | comparisons | notes |
|---|---|---|
| worst (reverse sorted) | n(n−1)/2 → **O(n²)** | also O(n²) swaps — far more swaps than selection sort |
| average | O(n²) | |
| best (already sorted, **with** `swapped` flag) | n−1 → **O(n)** | without the flag it's still O(n²) |
| space | O(1) | in place |
| stable? | **yes** — equal elements never swap past each other (strict `>`) | |

### C. Selection vs bubble — the comparison table you'll be asked for

| | selection | bubble |
|---|---|---|
| best case | O(n²) | O(n) with flag |
| worst case | O(n²) | O(n²) |
| swaps | ≤ n−1 (cheap when swaps are expensive) | up to O(n²) |
| stable | no | yes |
| adaptive (faster on nearly-sorted) | no | yes |
| which end gets fixed each pass | left (smallest) | right (largest) |

### D. Polymorphic version

```java
public static <T extends Comparable<T>> void bubbleSort(T[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        boolean swapped = false;
        for (int j = 0; j < a.length - 1 - i; j++) {
            if (a[j].compareTo(a[j + 1]) > 0) {           // only line that changed
                T tmp = a[j]; a[j] = a[j + 1]; a[j + 1] = tmp;
                swapped = true;
            }
        }
        if (!swapped) return;
    }
}
```

Descending order? Flip to `compareTo(...) < 0` — or better, keep the sort and reverse the `compareTo`/use a `Comparator`.

### E. Stability — why it matters

Sort students by GPA after they were sorted by name: a **stable** sort keeps equal-GPA students in name order. Bubble/insertion/merge are stable; selection isn't (the long-distance swap can jump an equal element).
