## 2. Today's concepts

### A. The node

```java
public class LinkedList<T> {
    private class Node {                 // private inner class — only the list touches nodes
        T data;
        Node next;
        Node(T data, Node next) { this.data = data; this.next = next; }
    }
    private Node head;                   // null when empty
    private int size;
```

Picture: `head → [A|•] → [B|•] → [C|null]`. No random access — to reach index *i* you walk *i* links.

### B. Core operations (draw the boxes!)

```java
    public void addToFront(T x) {                    // O(1)
        head = new Node(x, head);
        size++;
    }

    public void addToBack(T x) {                     // O(n) without a tail pointer
        Node n = new Node(x, null);
        if (head == null) { head = n; }
        else {
            Node cur = head;
            while (cur.next != null) cur = cur.next;     // walk to last node
            cur.next = n;
        }
        size++;
    }

    public void add(int index, T x) {                // O(n)
        if (index < 0 || index > size) throw new IndexOutOfBoundsException();
        if (index == 0) { addToFront(x); return; }
        Node prev = head;
        for (int i = 0; i < index - 1; i++) prev = prev.next;   // stop at the node BEFORE
        prev.next = new Node(x, prev.next);          // link new node in — order matters!
        size++;
    }

    public T removeFromFront() {                     // O(1)
        if (head == null) throw new NoSuchElementException();
        T out = head.data;
        head = head.next;
        size--;
        return out;
    }

    public T remove(int index) {                     // O(n)
        if (index < 0 || index >= size) throw new IndexOutOfBoundsException();
        if (index == 0) return removeFromFront();
        Node prev = head;
        for (int i = 0; i < index - 1; i++) prev = prev.next;
        T out = prev.next.data;
        prev.next = prev.next.next;                  // unlink
        size--;
        return out;
    }

    public T get(int index) {                        // O(n)
        Node cur = head;
        for (int i = 0; i < index; i++) cur = cur.next;
        return cur.data;
    }
```

Recurring bugs: forgetting the empty-list case; losing the rest of the list by setting `prev.next = newNode` **before** `newNode.next = prev.next`; off-by-one in "stop at the node before"; forgetting `size++/--`.

### C. `Iterable` and `Iterator` (20.8)

The for-each loop is sugar for an iterator:

```java
for (T x : list) { ... }
// ≡
Iterator<T> it = list.iterator();
while (it.hasNext()) { T x = it.next(); ... }
```

- `Iterable<T>` (java.lang): one method — `Iterator<T> iterator()`. **Implement this to make your class for-each-able.**
- `Iterator<T>` (java.util): `boolean hasNext()`, `T next()` (advances), optional `remove()`. `next()` past the end throws `NoSuchElementException`.

```java
public class LinkedList<T> implements Iterable<T> {
    ...
    @Override
    public Iterator<T> iterator() {
        return new Iterator<T>() {                       // anonymous class; a named private inner class is equally fine
            private Node cur = head;
            @Override public boolean hasNext() { return cur != null; }
            @Override public T next() {
                if (!hasNext()) throw new NoSuchElementException();
                T out = cur.data;
                cur = cur.next;
                return out;
            }
        };
    }
}
```

Why it matters for Big-O: iterating a linked list with `for (i < size) get(i)` is **O(n²)**; with an iterator it's **O(n)**.

### D. Async material checklist — Exceptions (12.1–12.9)

- Hierarchy: `Throwable` → `Exception` → `RuntimeException` (unchecked) / everything else checked; `Error` (e.g. `StackOverflowError`) — don't catch.
- `try { } catch (A e) { } catch (B e) { } finally { }` — specific first; `finally` runs even after `return`.
- `throws IOException` on the signature to propagate checked exceptions; callers must then handle/declare.
- Custom exception: `class InsufficientFundsException extends Exception { InsufficientFundsException(String m) { super(m); } }` (checked) — extend `RuntimeException` for unchecked.
- Multi-catch: `catch (IOException | NumberFormatException e)`.
- `e.getMessage()`, `e.printStackTrace()`; rethrow with `throw e;`.

### E. Async material checklist — File I/O (12.10–12.13)

```java
// reading
try (Scanner in = new Scanner(new File("data.txt"))) {        // try-with-resources auto-closes
    while (in.hasNextLine()) { String line = in.nextLine(); }
} catch (FileNotFoundException e) { ... }                      // checked!

// writing
try (PrintWriter out = new PrintWriter(new FileWriter("out.txt", true))) {   // true = append
    out.println("hello");
} catch (IOException e) { ... }
```
`File` doesn't open anything; `Scanner(File)` throws checked `FileNotFoundException`; `FileWriter` throws `IOException`. Always close (or use try-with-resources).

## 3. Self-check (~6 min)

1. Given `head → 1 → 2 → 3`, what does this leave?
   ```java
   Node n = new Node(9, null);
   head.next = n;
   n.next = head.next;
   ```
   <details><summary>Answer</summary><code>1 → 9 → 9 → …</code> — actually <code>n.next = n</code> (a self-loop), and 2→3 are lost. Should have set <code>n.next = head.next</code> <em>first</em>.</details>
2. Big-O of `addToFront`, `addToBack` (no tail), `get(i)`, `removeFromFront` for a singly linked list.
   <details><summary>Answer</summary>O(1), O(n), O(n), O(1).</details>
3. Which interface must a class implement to be used in a for-each loop, and what method does it require?
   <details><summary>Answer</summary><code>Iterable&lt;T&gt;</code>; <code>Iterator&lt;T&gt; iterator()</code>.</details>
4. What happens when `next()` is called after `hasNext()` returns false?
   <details><summary>Answer</summary>Should throw <code>NoSuchElementException</code>.</details>
5. Does this compile?
   ```java
   void read() { Scanner s = new Scanner(new File("x.txt")); }
   ```
   <details><summary>Answer</summary>No — unhandled checked <code>FileNotFoundException</code>. Add <code>throws FileNotFoundException</code> or try/catch.</details>
6. Does `finally` run here? What's returned?
   ```java
   static int f() { try { return 1; } finally { System.out.print("F"); } }
   ```
   <details><summary>Answer</summary>Yes, prints <code>F</code>; returns 1.</details>
