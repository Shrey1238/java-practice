## 1. Abstract classes & `final`
- `abstract class`: can't `new`; may have fields, constructors, concrete + abstract methods.
- Abstract method: no body; subclass must implement or be abstract; not `private`/`static`/`final`.
- `final class` no subclass; `final` method no override; `abstract final` is contradictory.

## 2. Polymorphism & casting
- **Static type** (declared) → what compiles. **Dynamic type** (object) → which override runs.
- Fields, `static` methods, and overload selection use static types.
- Upcast implicit; downcast explicit, run-time `ClassCastException` if wrong; unrelated types → compile error.
- `x instanceof T` true for T or subclasses; false for `null`. Pattern form `if (x instanceof Dog d)`.

## 3. Interfaces & `Comparable`
- Methods implicitly `public abstract`; fields `public static final`; implement with **`public`** methods.
- `class X extends A implements B, C`; interface can extend interfaces; no constructors.
- `Comparable<T>`: `int compareTo(T o)` neg/0/pos; `Integer.compare`, `Double.compare`, `String.compareTo`; consistent with `equals`.
- Interface vs abstract class: capability/no state vs is-a/shared code.

## 4. `ArrayList<E>` & generics (using)
- `add`, `add(i,x)`, `get`, `set`, `remove(int)` vs `remove(Object)`, `size()`, `contains`, `indexOf`; prints nicely.
- Reference types only (`Integer`); autoboxing. Invariant: `ArrayList<Circle>` ≠ `ArrayList<Shape>`.
- Wildcards: `? extends T` read/produce; `? super T` write/consume (PECS); `?` unbounded. `<T extends Comparable<T>>` bounded param.
- No structural modification inside for-each.

## 5. Big-O
- Drop constants & lower terms; worst case unless stated.
- O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ).
- Nested loops multiply; sequential add; halving → log n.
- ArrayList: `get` O(1); `add(0,x)`/`remove(0)`/`contains` O(n); `add` at end amortized O(1).
- LinkedList: front ops O(1); `get(i)` O(n); index-loop traversal O(n²).

## 6. Searching & sorting
| algorithm | best | worst | space | stable | key idea |
|---|---|---|---|---|---|
| linear search | O(1) | O(n) | — | — | scan |
| binary search | O(1) | O(log n) | — | — | **sorted**; `lo<=hi`, `mid=lo+(hi-lo)/2` |
| selection | O(n²) | O(n²) | O(1) | no | swap min into place; ≤ n−1 swaps |
| bubble | O(n) w/ flag | O(n²) | O(1) | yes | adjacent swaps; largest bubbles right |
| insertion | O(n) | O(n²) | O(1) | yes | shift bigger right, insert key |
| merge | O(n log n) | O(n log n) | O(n) | yes | split, recurse, merge |

Be able to: give the array after *k* passes of each; write selection/bubble/insertion from memory; write `merge`; sort `Comparable[]` via `compareTo`.

## 7. Recursion
- Base case + smaller recursive case; else `StackOverflowError`.
- Trace with indentation; print-before-call = forward order, print-after-call = reversed.
- Templates: factorial, sum(arr, i), reverse string, palindrome, power, fib (O(2ⁿ)), recursive binary search, helper-method idiom.
- Merge sort = recursion + merge.

## 8. ADTs, List, Linked list
- ADT = operations & meaning, not implementation (interface vs class).
- List ADT ops; array-backed: `E[] data; int size;` + doubling `resize`, `(E[]) new Object[n]`.
- Linked list: `Node {T data; Node next;}`, `head`, `size`.
  - addToFront O(1): `head = new Node(x, head)`.
  - middle insert: walk to node **before**, `prev.next = new Node(x, prev.next)`.
  - remove middle: `prev.next = prev.next.next`.
  - handle empty / index 0 separately; keep `size` in sync.

## 9. Iterable / Iterator
- `Iterable<T>` → `Iterator<T> iterator()` — makes for-each work.
- `Iterator<T>` → `hasNext()`, `next()` (advance; throw `NoSuchElementException` at end).
- Cursor lives in the iterator; `hasNext` has no side effects.

## 10. Exceptions (12.1–12.9)
- `Throwable` → `Exception` (checked) → `RuntimeException` (unchecked); `Error` separate.
- Common unchecked: NPE, `ArrayIndexOutOfBounds`, `IllegalArgumentException`, `ClassCastException`, `ArithmeticException`, `NumberFormatException`, `IndexOutOfBounds`, `NoSuchElementException`.
- Common checked: `IOException`, `FileNotFoundException`.
- `try/catch/finally`; specific before general; `finally` always runs (even after `return`); multi-catch `|`.
- `throws X` on signature to propagate checked; `throw new X("msg")`.
- Custom: `extends Exception` (checked) or `extends RuntimeException` (unchecked); constructor calls `super(msg)`.

## 11. File I/O (12.10–12.13)
- `new Scanner(new File("f.txt"))` → checked `FileNotFoundException`; `hasNextLine()/nextLine()`, `hasNextInt()/nextInt()`.
- `new PrintWriter(new FileWriter("f.txt", append))` → `IOException`; `println`.
- try-with-resources closes automatically; otherwise `close()`.
