## 1. Warm-up traces (write your answer, then expand)

**1. Polymorphism + overloading**
```java
class A { String f(A x) { return "A-A"; } String f(B x) { return "A-B"; } }
class B extends A { @Override String f(A x) { return "B-A"; } }
A a = new B(); B b = new B();
System.out.println(a.f(a) + " " + a.f(b) + " " + b.f(b));
```
<details><summary>Answer</summary><code>B-A A-B A-B</code>. <code>a.f(a)</code>: overload <code>f(A)</code> by static type, dispatched to B's override. <code>a.f(b)</code>: overload <code>f(B)</code> (static type B) — B doesn't override it → A's. <code>b.f(b)</code>: same.</details>

**2. Recursion order**

```java
    g(s.substring(1));
    System.out.print(s.charAt(0));

g("abc");
```
<details><summary>Answer</summary><code>cba</code> — print after the call → reversed.</details>

**5. Exceptions flow**
```java
static String h(int x) {
    try {
        if (x < 0) throw new IllegalArgumentException("neg");
        return "ok";
    } catch (IllegalArgumentException e) {
        return "caught";
    } finally {
        System.out.print("F ");
    }
}
System.out.println(h(-1) + " " + h(1));
```
<details><summary>Answer</summary><code>F F caught ok</code> — both calls print <code>F</code> (during evaluation) before the concatenated line prints.</details>

**7. Generics**

**8. Iterator**
```java
Iterator<String> it = list.iterator();   // list = [x, y]
while (it.hasNext()) { it.next(); System.out.print(it.next()); }
```
<details><summary>Answer</summary>Prints <code>y</code>, then the loop ends (hasNext false). With an odd-length list the second <code>next()</code> would throw <code>NoSuchElementException</code>.</details>
