## 2. Today's concepts

### A. MVC — Model · View · Controller

| part | job | in Spring |
|---|---|---|
| **Model** | data to display | a `Model` object you put attributes into (+ your domain classes) |
| **View** | how it's rendered | an HTML **template** (Thymeleaf) in `src/main/resources/templates/` |
| **Controller** | handles request, fills model, picks view | `@Controller` class returning a **view name** (String) |

Request flow: browser `GET /todos` → DispatcherServlet → your controller method → returns `"todos"` → Thymeleaf renders `templates/todos.html` with the model → HTML back to browser.

### B. `@Controller` vs `@RestController`

```java
@Controller                                  // NOT @RestController — return values are VIEW NAMES
@RequestMapping("/todos")
public class TodoWebController {
    private final TodoService service;
    public TodoWebController(TodoService service) { this.service = service; }

    @GetMapping
    public String list(Model model) {
        model.addAttribute("todos", service.findAll());     // key "todos" is what the template uses
        return "todos";                                     // → templates/todos.html
    }

    @PostMapping
    public String add(@RequestParam String title) {         // form field named "title"
        service.add(title);
        return "redirect:/todos";                           // Post-Redirect-Get: avoid double submit on refresh
    }

    @PostMapping("/{id}/delete")
    public String delete(@PathVariable long id) {
        service.delete(id);
        return "redirect:/todos";
    }
}
```

If you annotate with `@Controller` and want raw data from one method, add `@ResponseBody` to that method. `@RestController` = `@Controller` + `@ResponseBody` on everything.

### C. Thymeleaf — templates

Plain HTML with `th:` attributes; add `xmlns:th="http://www.thymeleaf.org"` to `<html>`.

```html
<h1 th:text="${title}">Placeholder</h1>                        <!-- replaces element text -->

<ul>
  <li th:each="t : ${todos}">                                   <!-- loop -->
    <span th:text="${t.title}">title</span>                     <!-- calls getTitle() -->
    <span th:if="${t.done}">✓</span>                            <!-- conditional -->
    <span th:unless="${t.done}">○</span>
    <form th:action="@{/todos/{id}/delete(id=${t.id})}" method="post">   <!-- URL with path var -->
      <button>delete</button>
    </form>
  </li>
</ul>
<p th:if="${#lists.isEmpty(todos)}">Nothing to do!</p>

<form th:action="@{/todos}" method="post">
  <input name="title" required>                                 <!-- name → @RequestParam String title -->
  <button>Add</button>
</form>

<a th:href="@{/todos}">All</a>
```

Expression cheat sheet:
- `${...}` — variable from the model (`${t.title}` → `t.getTitle()`; Map keys and record components also work).
- `@{...}` — URL (handles context path; `@{/x/{id}(id=${v})}` for path variables, `@{/x(page=1)}` for query params).
- `#{...}` — message/i18n; `*{...}` — field of the selected object in a form (`th:object`).
- Utility objects: `#lists`, `#strings`, `#dates`, `#numbers`.

### D. Forms and binding

- Simple: `@RequestParam String title` per input `name`.
- Object binding: `th:object="${todo}"` + `th:field="*{title}"` in the template, `@ModelAttribute Todo todo` in the controller — Spring builds the object from form fields via setters.
- `@RequestParam(required = false, defaultValue = "…")` for optional params.

### E. Static files & config

- `src/main/resources/static/` → CSS/JS/images served at `/style.css` etc.
- `src/main/resources/templates/` → Thymeleaf views (only reachable via a controller).
- `application.properties`: `server.port=8081`, `spring.thymeleaf.cache=false` for dev.

## 3. Self-check (~5 min)

1. A `@Controller` method returns `"home"`. What file is rendered? What if it were `@RestController`?
   <details><summary>Answer</summary><code>templates/home.html</code>; with <code>@RestController</code> the literal string <code>home</code> is the response body.</details>
2. Why `return "redirect:/todos"` after a POST instead of `return "todos"`?
   <details><summary>Answer</summary>Post-Redirect-Get — a browser refresh would otherwise resubmit the form (duplicate todo).</details>
3. `th:text="${todo.title}"` — what Java method must exist?
   <details><summary>Answer</summary><code>getTitle()</code> (or a record component <code>title()</code>).</details>
4. Which expression syntax builds a link: `${/todos}` or `@{/todos}`?
   <details><summary>Answer</summary><code>@{/todos}</code>.</details>
5. Where does `<input name="qty">` end up in the controller?
   <details><summary>Answer</summary><code>@RequestParam int qty</code> (or a field named <code>qty</code> on a <code>@ModelAttribute</code> object).</details>
