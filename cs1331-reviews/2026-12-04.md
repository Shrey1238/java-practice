## 1. Spring Boot — the one-pager (Nov 20 → Dec 2)

### Bootstrapping
- `@SpringBootApplication` class with `main` → `SpringApplication.run(App.class, args)`; embedded Tomcat on 8080.
- Layout: `src/main/java/<base>/…` (components in sub-packages of the app class), `src/main/resources/{application.properties, templates/, static/}`, `pom.xml` starters.

### IoC / DI / Beans
- **Bean** = container-managed object; found by component scan via `@Component`, `@Service`, `@Repository`, `@Controller`/`@RestController`, or produced by `@Bean` in a `@Configuration`.
- **DI** = dependencies passed in (constructor injection preferred, by type). **IoC** = container creates & wires.
- Singleton scope by default. Ambiguous type → `@Primary`/`@Qualifier`; none → startup failure.

### Web layer
| | `@RestController` | `@Controller` |
|---|---|---|
| returns | data → JSON | view name → `templates/<name>.html` |
| params | `@PathVariable`, `@RequestParam`, `@RequestBody` | `@PathVariable`, `@RequestParam`, `@ModelAttribute`, `Model` |
| mappings | `@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping`, class-level `@RequestMapping` | same |
- HTTP verbs: GET read, POST create, PUT/PATCH update, DELETE delete; status 200/201/404/400/500.
- `redirect:/path` after form POST.

### Thymeleaf
- `th:text`, `th:each="x : ${list}"`, `th:if`/`th:unless`, `th:href="@{/url}"`, `th:action`, `th:object`/`th:field="*{prop}"`.
- `${...}` model value (calls getters); `@{...}` URL; `#lists`, `#strings` utilities.

### Persistence
- JPA (spec) / Hibernate (impl) / Spring Data JPA (repositories).
- `@Entity`, `@Id`, `@GeneratedValue(strategy = IDENTITY)`, `@Table`, `@Column`, no-arg constructor, wrapper `Long id`.
- `interface TodoRepository extends JpaRepository<Todo, Long>` → `save`, `findById` (`Optional`), `findAll`, `deleteById`, `count`, + derived `findByXxx…`.
- H2 in-memory DB; `spring.jpa.hibernate.ddl-auto=update`, `spring.jpa.show-sql=true`.

### Typical Spring Boot exam questions (conceptual, not "write an app")
1. Match annotation → purpose (`@Service`, `@PathVariable`, `@Entity`, `@Id`, `@GetMapping`, `@Autowired`, `@RequestBody`).
2. Explain DI/IoC and why constructor injection + interfaces help testing.
3. Given a controller method, say what URL/verb hits it and what's returned.
4. Given `findByTitleContaining(String)`, describe the query. What does `findById` return?
5. `@Controller` vs `@RestController`; `${}` vs `@{}`.
6. Which layer does X belong in (controller/service/repository)?

## 3. Self-check (~5 min)

1. In one sentence each: what do `@Service`, `@Repository`, and `@RestController` have in common, and how do they differ?
   <details><summary>Answer</summary>All are <code>@Component</code> stereotypes making the class a bean; they signal layer (logic / data access with exception translation / web returning response bodies).</details>
2. A form POSTs `title=study` to `/todos`. Write the controller method signature (MVC style).
   <details><summary>Answer</summary><code>@PostMapping("/todos") public String add(@RequestParam String title)</code> … <code>return "redirect:/todos";</code></details>
3. `repo.findById(5L).get()` — risk?
   <details><summary>Answer</summary><code>NoSuchElementException</code> if absent; prefer <code>orElseThrow()</code>/<code>orElse</code>/<code>ifPresent</code>.</details>
4. Which collection gives sorted iteration with O(log n) insert? Which gives O(1) insert with insertion-order iteration?
   <details><summary>Answer</summary><code>TreeSet</code>/<code>TreeMap</code>; <code>LinkedHashSet</code>/<code>LinkedHashMap</code>.</details>
5. Why is a `PriorityQueue<Task>` a compile-time OK but runtime failure if `Task` isn't `Comparable` and no `Comparator` is given?
   <details><summary>Answer</summary>The generic signature doesn't require <code>Comparable</code>; the first insert that needs ordering throws <code>ClassCastException</code>.</details>
