## 1. The 25 gotchas (all-semester)

**Basics & control flow**
1. `int / int` truncates: `7 / 2 == 3`; `7 / 2.0 == 3.5`. `%` keeps the sign of the left operand.
2. `==` on Strings/objects compares references — use `.equals`. `char + int` is arithmetic (`'a' + 1 == 98`).
3. `switch` falls through without `break`; arrow-form `case X ->` doesn't.
4. Compound assignment casts implicitly: `byte b = 10; b += 5;` OK, `b = b + 5;` error.
5. `Scanner.nextInt()` leaves the newline — follow with `nextLine()` to clear it.

**Arrays & methods**
6. Arrays are objects: `int[] b = a` aliases. `a.length` (no parens) vs `s.length()` vs `list.size()`.
7. Pass-by-value always: a method can mutate the array/object a reference points to, but can't rebind the caller's variable.
8. Default values: `0`, `0.0`, `false`, `'\u0000'`, `null` for object arrays — `Circle[] cs = new Circle[3]; cs[0].area()` → NPE.
9. 2-D arrays are arrays of arrays; rows can be ragged; `grid.length` rows, `grid[i].length` columns.

**Classes & inheritance**
10. Writing any constructor removes the default; `this(...)`/`super(...)` must be first; implicit `super()` needs a parent no-arg constructor.
11. Order: parent ctor → child field initializers → child ctor body.
12. `static` members can't touch instance members or `this`. Static/field access uses the *static type*; overridden methods use the *dynamic type*.
13. Overriding: same signature, `@Override`, no narrowing visibility, not `static/private/final`. Overloading: different params, compile-time.
14. `equals(Object)` recipe + matching `hashCode`; `equals(Dog)` is an overload trap.
15. Copy constructor: shallow shares mutable objects; deep copies them (`Arrays.copyOf`). Strings/immutables can be shared.

**Abstract / interface / polymorphism**
16. `new AbstractThing()` ✗; abstract methods no body; concrete subclass must implement all. Interface methods are implicitly `public abstract` — implement with `public`.
17. Downcast compiles if related, `ClassCastException` if wrong at runtime; unrelated types don't compile. `instanceof` before casting.
18. `compareTo`: negative/zero/positive; use `Integer.compare`, never subtraction for possibly-large values.

**Generics & collections**
19. `ArrayList<int>` ✗; `list.remove(int)` is by index, `remove(Object)` by value; generics invariant → wildcards (`? extends` read, `? super` write).
20. Erasure: no `new T()`, `new T[]`, `instanceof T`; use `(T[]) new Object[n]`.
21. Don't modify a collection inside for-each (`ConcurrentModificationException`); `HashSet`/`HashMap` need `hashCode`+`equals`; `TreeSet`/`PriorityQueue` need `Comparable`.
22. `Queue.poll()` → `null` when empty, `remove()` throws; `Map.get` → `null` when missing; `List.of` is immutable.

**Algorithms & recursion**
23. Big-O: nested → multiply, sequential → add, halving → log; drop constants. Selection O(n²) always; bubble/insertion O(n) best; merge O(n log n) always with O(n) space; binary search needs sorted input.
24. Recursion: base case first; print-before vs print-after reverses order; `StackOverflowError` without progress toward base case.

**Linked lists, iterators, exceptions, I/O**
25. Link the new node's `next` *before* re-pointing `prev.next`; handle empty/index-0; `Iterator.next()` throws `NoSuchElementException` at end; checked exceptions must be caught or declared; `finally` always runs; `new Scanner(new File(...))` throws checked `FileNotFoundException`.
